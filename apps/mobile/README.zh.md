# DeepSeek Harness 手机端

[English](README.md) | 中文

这是已有 DeepSeek Harness Web 会话的 Expo/React Native 手机伴侣。它扫描或粘贴 `dsh web` 生成的二维码，把配对主机保存到操作系统安全存储，通过加密局域网载体自动重连，列出非空且未归档的根会话，显示其中用户与助手的纯文本消息，并跟随 Web 会话实时显示上下文注入、Think、步骤、工具、审批和提问状态；它还会把文字与受支持的光栅图片提交到选中的同一个 Session。对话常驻在左侧导航抽屉下方；抽屉按工作目录归组会话，并重复显示最近五段会话以便快速进入。打开会话时先读取最近六条模型消息，并把记录定位到最新消息；点击“加载更早记录”会每次向前读取六条，同时保留当前可见位置。输入栏从 Host 读取所选 Session 已配置的 provider/model 目录，并通过与浏览器相同的 Session API 应用模型切换。新建会话会在当前工作区创建空白 Session 并立即打开；工作区支持搜索、按名称或最近活动排序，以及独立展开和收起。设置页提供通用设置、模型、插件和 Agent 预设四个入口，具体配置页面暂留后续迭代。

品牌组合标志与产品图标来自已确认的手机端构图，并随应用打包；可见图标尺寸与符合平台规范的点击区域相互独立。

```sh
pnpm install
pnpm --filter @deepseek-ai/dsh-mobile start
```

请在与 Harness 电脑连接同一网络的手机上使用 Expo Go 或 development build。源码运行时在电脑执行 `pnpm dsh web`，已安装版本执行 `dsh web`，随后扫描终端二维码。

## 安全性

配对信息可通过 `dsh://pair?code=...` 深链接或二维码导入。持久 token 保存在 `expo-secure-store`；每次 WebSocket 连接都会生成新的 Curve25519 手机密钥对，而且 token 只会在 XSalsa20-Poly1305 加密启用后发送。Android 发布版 manifest 允许局域网直连 `ws://` socket，因为每个应用帧都经过认证和加密。RPC allowlist、模型选择与图片准入均由主机校验，而不是依赖手机应用。

## 已知限制

- 目前只支持局域网直连。如果存在 NAT，或手机无法访问配对信息中的 `ws://` 地址，应用将无法连接。
- 一次连接尝试同时覆盖 socket 建立与加密认证。超时后，应用会保留配对信息、显示当前连接地址，并提供“重试”或“忘记电脑”。
- 普通对话消息仍按纯文本显示，同时把上下文、Think、工具、审批和提问状态按 Web 端事件顺序直接插入助手气泡，并显示在流式回复之前。抽屉中的工作区名称来自 Session 工作目录，新增工作区仍需在 Web 端完成。附件选择器仅接受 PNG、JPEG、WebP 与 GIF 图片，不支持通用文档。Markdown 渲染、交互式审批或问题回答、取消、终端、文件、Git、语音输入与协作仍不可用；为这些能力预留的布局控件会明确显示为禁用状态。
- 应用只保存一个配对主机。配对另一台电脑前请使用“忘记电脑”。
