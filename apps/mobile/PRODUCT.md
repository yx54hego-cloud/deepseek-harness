# Product

## Register

product

## Platform

adaptive

## Users

DeepSeek Harness users who leave an agent running on their computer and need to check the same conversation or send a short follow-up from a phone on the same trusted network.

## Product Purpose

The companion provides a narrow remote conversation surface: pair once, choose an existing Harness session, read its current text transcript, and send a plain-text instruction into that same session. Success means the phone and browser converge on one durable conversation without exposing the browser's broader remote-code-execution surface.

## Positioning

The smallest secure bridge from a phone to an existing DeepSeek Harness conversation.

## Brand Personality

Quiet, direct, and trustworthy. The interface should feel like a focused native utility rather than a second desktop workspace.

## Anti-references

Do not reproduce Orca's worktree, terminal, collaboration, file, Git, or orchestration surfaces. Avoid dashboard density, decorative AI imagery, terminal aesthetics, and controls that imply unsupported remote-computer access.

## Design Principles

- Put the current conversation ahead of host or protocol details.
- Make connection state visible without competing with the task.
- Use familiar native navigation and input behavior on both platforms.
- Explain empty and failed states with one concrete recovery action.
- Keep security decisions in the protocol; never ask users to manage cryptographic material.

## Accessibility & Inclusion

Honor safe areas, system font scaling, screen readers, dark appearance, reduced motion, and minimum 48 dp Android or 44 pt iOS touch targets. Status must never rely on color alone.
